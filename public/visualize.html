What the app does

🤖AI Face Matching
Users upload a half-face AI photo. The server runs a Python compare.py script (DeepFace) to find other users whose profile photos match above a similarity threshold (0.68).
💬Private Chat Rooms
Each match creates a unique room_Id derived from both users' sorted MongoDB IDs. Messages are persisted in MongoDB and delivered in real-time via Socket.IO rooms.
🔐JWT Authentication
On login a JWT is created and stored as an HTTP cookie (uid). Protected routes use a middleware that validates the token on every request. Passwords are hashed with bcrypt (10 rounds).

User journey

Socket.IO events

📥 joinRoom

Emitted by the client after navigating to a chat page. The server calls socket.join(roomId) so the socket is subscribed to that private room channel.

💬 messageFromUser (client → server)

Carries { roomId, message, senderId }. The server persists the message to MongoDB, then re-emits the event back to all sockets in the room.

📤 messageFromUser (server → clients)

Broadcast to all members of the chat room so every open tab receives the new message in real-time without polling.

🗄️ Message persistence

Each message is saved in ChatModel under its room_Id. On page load, old messages are fetched from MongoDB and rendered server-side via EJS before the socket connection is established.


Chat room ID derivation

🔑Deterministic Room ID
roomId = [userA._id, userB._id].sort().join("_")

Sorting both IDs ensures that whether UserA or UserB initiates the comparison, they always land in the same room — no duplicate channels are ever created.
